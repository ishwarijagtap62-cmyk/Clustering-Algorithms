## Overview

This project applies three clustering algorithms to a real-world dataset and compares them using internal evaluation metrics and visual inspection:

- **K-Means**
- **Hierarchical clustering (Ward linkage)**
- **DBSCAN**

The cultivar labels in the dataset are used **only as an external reference** (Adjusted Rand Index). They are never used to fit or tune any model.

## Dataset

- **Name:** Wine Recognition (UCI Wine) dataset
- **Source:** https://archive.ics.uci.edu/dataset/109/wine
- **Size:** 178 records, 13 numeric chemical features
- **Quality:** no missing values, no duplicates (verified by the script)
- **Loading:** the script uses `sklearn.datasets.load_wine()`, so no download is needed

## Methodology

1. Load and inspect the data (shape, missing values, duplicates, statistics).
2. Standardise all features with `StandardScaler` (z-score).
3. Choose parameters:
   - **k** from the elbow curve, Silhouette Score and Davies–Bouldin Index for k = 2 to 8 (k with highest K-Means silhouette).
   - **DBSCAN** `eps` and `min_samples` by grid search, keeping only settings with at least 2 clusters and at most 30 % noise.
4. Fit the final models.
5. Evaluate with Silhouette Score (higher is better) and Davies–Bouldin Index (lower is better). DBSCAN noise points are excluded, and `NaN` is returned if fewer than 2 clusters exist.
6. Visualise with PCA scatter plots, a dendrogram, a k-distance plot and a cluster-profile heatmap.
7. Run built-in self-tests.

## Results

Results from one run with random seed 42 (scikit-learn 1.8.0, Python 3.12.3):

| Algorithm | Parameters | Clusters | Noise | Silhouette | Davies–Bouldin | ARI (reference) |
|---|---|---|---|---|---|---|
| K-Means | k = 3 | 3 | 0 | 0.2849 | 1.3892 | 0.8975 |
| Hierarchical (Ward) | k = 3 | 3 | 0 | 0.2774 | 1.4186 | 0.7899 |
| DBSCAN | eps = 2.3, min_samples = 8 | 2 | 52 | 0.3422* | 1.1261* | 0.5047* |

\* DBSCAN scores are computed on the non-noise points only, so they are **not directly comparable** with the other two rows.

**Takeaway:** K-Means (k = 3) was the most suitable of the three tested methods, but its margin over Ward is small. All silhouette values are modest (below 0.35), so the clusters overlap and should be treated as tendencies, not definitive categories. See the report for the full analysis and limitations.
